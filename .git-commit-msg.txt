Simplify attendance tables to Time In / Start Break / End Break / Time Out

Owner feedback: having both Morning/Afternoon In/Out (4 columns) and
Break In/Break Out (2 more) side by side looked like the same break was
being recorded twice, and the wording didn't match what's actually on the
kiosk. The Morning/Afternoon model predates break-punching and was really
a segment-index guess at "did they take lunch" -- now that the kiosk has
dedicated Start Break/End Break buttons, that guesswork isn't needed for
the common case.

Replace computeDaySlots + computeBreakSlot in attendanceSlots.ts with one
computeDayTimeline() that returns exactly the four things the kiosk itself
offers: Time In (day's first IN), Start Break, End Break, Time Out (day's
last OUT). Wire it into the admin Attendance page (Today dashboard + the
per-employee week/month table) and the Employee Dashboard's Attendance
History table, replacing the old 6-column layout with these 4. The raw
punch history (including any unusual multi-segment days) is still fully
visible via the admin's existing Manage popover -- this change only
simplifies the summary table.
